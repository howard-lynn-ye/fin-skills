# Code of conduct

This project is small, and its whole method is people telling each other, with evidence, that
a claim is wrong. That only works if being wrong is safe and being rude is not.

## Expected

- Argue from reproductions, primary sources and version numbers, not from seniority or tone.
- Assume a wrong claim was an honest mistake; the commit history shows several were.
- Say what you verified and what you did not, and mark the difference.
- Keep review comments about the work, and specific enough to act on.
- Accept a correction gracefully, and thank the person who ran the code.

## Not accepted

- Insults, harassment or personal attacks, in public or in private.
- Publishing someone's private information, or contacting people outside GitHub without their
  agreement.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Dismissing a reproduction because of who reported it.
- Reopening a settled measurement again and again without new evidence.

## Scope

This applies in every space the project runs: issues, pull requests, discussions, commit
messages, and any channel where someone represents the project.

## Enforcement

The maintainer named in `MAINTAINERS.md` handles reports and decides on consequences, which
range from a request to edit a comment, through a warning, to a temporary or permanent ban from
the project's spaces. To report, open a GitHub issue with `[conduct]` at the start of the
title and only as much detail as you are comfortable making public, and say if you want the
rest handled privately; the maintainer will reply with a private channel. Reports are
acknowledged within seven days. A report about the maintainer goes to the other admin named in
`MAINTAINERS.md`.

## Reference standard

This is a short, original text. Where it is silent, the Contributor Covenant version 2.1 is the
reference standard: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
