## [0.1.0] - 2026-09-09

First release. The `v0.1.0` tag marks the state of `master` on 2026-09-09; everything below
was committed between 2026-09-03 (ceb0f69, the initial commit) and 2026-09-09.

### Added

- 53 Agent Skills across seven plugins: 29 domain skills (fin-core 19, fin-china 2,
  fin-asia 1, fin-crypto 1, fin-futures-fx 2, fin-llm 4) and 24 opt-in per-library skills in
  fin-libraries (975412e). Every frontmatter is restricted to the six-field portable subset
  that `scripts/validate.py` enforces, so the skills upload to claude.ai unchanged.
- The skills as an importable package: `fin_skills/` is generated from the skills by
  `scripts/build_package.py` - skill texts and references as package data, guard scripts as
  modules - and installs with `pip install git+https://github.com/howard-lynn-ye/fin-skills`
  (9a2fc6f). The hand-written `fin_skills/api/` layer survives regeneration (0543469).
- A unified API, `fin_skills.api`: 28 guards behind one interface, each returning a
  `GuardResult` instead of raising, a typed `conventions` module and `run_all` (c600109); and `Bundle`, one
  container for the artefacts of a research run whose `check()` runs every guard whose inputs
  are present (1c6b6e5).
- A test suite under `tests/`: 505 fast tests across every generated module and the API layer,
  with the long demo paths marked `slow` and deselected by default (bda8876).
- An API reference built with pdoc by `scripts/build_docs.py` and published to GitHub Pages
  at https://howard-lynn-ye.github.io/fin-skills/ (cfd00cd, 6ffc954, 3bb2ced).
- Marketplace federation: eight third-party finance skill packs listed by their own GitHub
  source in `.claude-plugin/marketplace.json`, installed disabled, each with
  `metadata.verified_on`; `catalog/federation-notes.md` records what was checked and what was
  left out (d2e5efb, ca719e0).
- `benchmarks/leak_bench.py`, the leak benchmark: a defect x guard detection matrix on a
  seeded synthetic world, with `benchmarks/RESULTS.md` regenerated by the script (added with
  this release; see `benchmarks/README.md` for the method).
- Trigger evaluation: `scripts/eval_triggers.py`, a lexical proxy, and `scripts/eval_blind.py`,
  a model choosing from the skill listing alone (eee98fc, e871dcd); the final blind result on
  the 53 skills is 107/108 on 108 queries (b2ac791).
- Regeneration and checking scripts: `build_index.py`, `build_package.py`, `validate.py`,
  `check_scripts.py` (64cb5b3), `check_drift.py`, `check_repo_stats.py`.
- LF line endings forced by `.gitattributes` so the generated package checks identically on
  every OS (2f857d1, 12d5b25).

### Fixed

- Back-adjusted futures: the difference-adjusted continuous contract in
  `fin_skills.futures_fx.continuous_contract` now adds the roll gap instead of subtracting
  it. The inverted sign was caught by the test suite (ef45b5e).
- Claims corrected after re-measurement, each dated in the skill it lives in: the Alpaca
  paper-trading safety claim was backwards (e3be203); exchange_calendars and futu-api
  (d0e5892); FinRL status (b4d1a6a); the event-study variance claim (bcc4932); the
  adjustment-convention framing (eadd486); the fin-libraries listing cost (623dff0).
- Skill-routing defects found by the blind evaluations: disambiguation and pointer defects
  (8fdbec1, cece347, f78b0c9, ea7a12a) and content a concurrent writer dropped from eight
  library skills (aab5ba3).
- Five stale or wrong statements in README.md and AGENTS.md found by the maturity review
  (aa5b56d).
