# 现成代码接入后的第一轮结果

记录日期：2026-09-21，America/New_York。实验在 Beacon RADFM 完成主比较；
代码沿用 fruit-fly-fund、Stonkfly 和 Stonkfly Lab，具体接口、假设及版本见
[README](README.md)。本轮没有调整参数后挑选最好种子。

## 紧凑模型：有正收益，但未超过普通方法

Kraken BTC-USDC 日线。训练为 2024-10-23 至 2025-12-15，验证为 2025-12-16 至
2026-05-04，测试为 **2026-05-05 至 2026-09-21**。下表是测试段累计净收益，
已计入模拟手续费和买卖价差，不是年化收益。学习器结果取五个预设种子的平均。

| 方法 | 平均累计净收益 | 平均成交次数 |
|---|---:|---:|
| 果蝇记忆＋风险门控 | **+2.3261%** | 4.0 |
| 果蝇记忆 | +0.8744% | 13.2 |
| 冻结果蝇记忆，无门控 | +2.2865% | 44.6 |
| 打乱反馈 | −0.1077% | 2.8 |
| 普通学习器＋相同风险门控 | +4.6800% | 14.6 |
| 普通学习器 | **+6.0627%** | 20.0 |
| 买入持有，使用相同执行限制 | +6.7317% | 单次入场 |
| 现金 | 0.0000% | 0 |

果蝇配置加门控后的平均收益提高了 1.4517 个百分点，同时换手下降；但它仍落后于
同样加门控的普通学习器 2.3539 个百分点。对普通学习器，门控反而降低平均收益。
所以当前证据支持“接入可以运行，某个门控配置改变了结果”，不支持“果蝇机制优于
普通方法”或“门控总是有效”。

五个种子的果蝇＋门控收益分别为 +0.6942%、0%、+5.4681%、0%、+5.4681%。
其中种子 23、53 在测试段没有成交，不能把零收益说成成功避险的学习证据。
无门控果蝇的种子 37 只有一次入场，收益恰好等于买入持有；权重发生变化本身不证明
学会了择时。未测试“冻结记忆＋同样门控”这一额外组合，因此不从跨配置差异单独归因
门控条件下的记忆贡献。

这些是同一条行情路径上的算法种子差异，不是五个独立市场；测试段仍是开发证据。
当前资产、期间、成本、目标与旧 ECB 实验不同，不能直接把旧收益与本轮相减当作改进量。

## 实际验证和证据

- 本地适配检查：8 项通过。Beacon 同一组检查也通过。
- Beacon 完整连接组检查：7 项通过，包括此前在本地跳过的完整图测试。
- 逐笔执行复用上游 Decimal 账本；独立使用 fin-skills 成本函数及现金、数量算术核对。
- 每笔成交晚于其决策；验证／测试权重哈希保持不变，冻结训练组的权重也保持不变。
- 已核对下载的行情哈希、部署 Python 源码与当前提交一致。
- 另用不导入策略或上游账本的标准库脚本，从成交重建 94 个窗口、6,841 笔成交和
  21,530 个净值点，全部一致。故意改坏一笔费用的负对照被正确拒绝。

完整主实验输出见 [compact_v1.json](evidence/compact_v1.json)。
[summarize.py](summarize.py) 从该文件计算全部均值和配对差值，并检查种子覆盖、时间划分、
账本标记与权重冻结。收益序列、成交明细、SQLite 账本与原始行情保存在 RADFM 运行目录。
独立重建脚本为 [audit_evidence.py](audit_evidence.py)，核对结果为
[compact_audit_v1.json](evidence/compact_audit_v1.json)。

成本采用固定假设：单边佣金 8 bps、半价差 2.5 bps；不是实时费率或历史逐笔报价。
终点持仓按 bid 计价，没有虚构平仓，也没有计入尚未发生的最终清仓费用。
完整连接组使用更短区间，结果另列，不与本表直接排名。
