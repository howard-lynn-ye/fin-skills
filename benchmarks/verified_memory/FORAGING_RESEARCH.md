# 从果蝇觅食行为到交易控制器：文献与设计依据

日期：2026-09-21。性质：研究设计备忘录；不是盈利结果或已实现模型。

后续执行更新：原模型数值复现、交易反馈接口与最小进入／持有／退出任务测试已运行，见
[执行结果](../fly_paper/RESULTS.md)。本备忘录下面的“未运行”记录保留研究设计当时的状态。

建议把研究主线定为：**内部资源状态调节的觅食决策，以及经验如何改变持续、退出和再次进入。**
模型要解释的是“为什么继续、为什么离开、什么经验值得记住”，而不只是把市场特征送入
一个冠以果蝇名称的稀疏网络。以下明确区分实验发现、工程对应和待验证假设。

本轮阅读了下列原始论文的相关正文、摘要及可用代码说明；没有运行作者代码。

## 可以真正约束设计的果蝇研究

| 证据 | 原研究发现 | 对交易的工程启发 | 不能直接推出的结论 |
|---|---|---|---|
| E1，Corrales-Carvajal 等，2016 | 营养与生殖状态影响果蝇在蛋白食源处停下、停留和离开；探索与利用依赖具体内部需求。 | 同一外部机会，在不同现金、库存和风险余量下，应有不同的进入和退出倾向。 | 不能概括成“越饿越冒险”，更不能把亏损映射成加杠杆的饥饿信号。 |
| E2，Sayin 等，2019 | 饥饿果蝇在没有食物奖励的重复试验中仍持续追踪气味；MBON/DAN 参与持续行为，VPM4 章鱼胺神经元可抑制追踪。 | 分开实现持续利用与可中断退出，让二者受状态和新证据调节。 | 生物的坚持不等于经济最优；不能照搬成亏损后坚持追单。 |
| E3，van Breugel，2021 | 对无食物的气味斑块，离开后的搜索与此前访问间隔相关；作者的行为模型研究了这种相关决策的搜索效率。 | 退出后保留经验，重访等待和搜索预算可以依赖历史。 | 不是“吃完资源所以离开”的实验证据，也未证明果蝇遵循某个金融收益阈值。 |
| E4，Huetteroth 等，2015 | 甜味与营养价值通过不同的奖励性多巴胺通路支持不同时间尺度的记忆。 | 区分吸引人的信号、近期经验和经过观察窗口检验的价值。 | 不能简单等同为甜味总是即时、营养总是延迟；不能把看涨信号当作已经获得的利润。 |
| E5，Musso 等，2017 | 果蝇能通过摄食后的经验学到甜味物质没有热量，形成降低其价值的“热量落空记忆”。 | 对反复有吸引力、但扣除成本后不产生收益的机会形成负面经验。 | 数据缺失不等于预期收益落空；必须先确认反馈窗口结束且记录有效。 |
| E6，Felsenberg 等，2018 | 在该厌恶记忆消退实验中，新形成的相反记忆与原记忆并存，共同影响行为。 | 环境改变时允许新经验抑制旧策略，保留条件性记忆以供再评估。 | 不代表所有遗忘都不擦除记忆，也没有证明金融状态会周期性复现。 |
| E7，Huang、Luo、Woo 等，2024 | 短期与长期记忆单元通过 MBON–DAN 反馈相互作用；连接组约束模型包含不同保留时间及双向可塑性。 | 优先复现已发表的记忆动力学，再研究如何接入交易控制。 | 原研究主要是厌恶条件学习；不是完整觅食脑模型，也没有提供交易信用分配算法。 |

E1 是行为层面的主要依据；E2 为持续与退出提供回路依据；E4/E5 为“线索吸引力与
实际价值分开”提供依据；E7 是优先考虑的可复现记忆模块。它们来自不同实验，
**不能直接拼起来就声称复现了一个已被验证的完整果蝇回路。**

补充证据 E8 研究代谢状态、味觉与探索利用，但本次读取的是标明未经同行评审的
bioRxiv 版本。它只作为补充，不承担主要机制结论。

## 交易任务应该怎样对应

### 食源不是永久赚钱的某只股票

将一个“食源”定义为 **资产或策略与当前可观测市场条件的组合**。
同一资产在不同条件下可以是不同机会；模型只能使用当时可见的信息推断条件，
不能读取模拟器的隐藏状态标签。小交易者也不会像吃食物一样消耗掉市场收益，
除非环境明确模拟了市场冲击，因此不把资源耗尽硬套到价格过程。

建议行为流程：

```text
观察候选机会 → 判断是否值得进入 → 持续持有/利用 → 退出或切换 → 再评估旧机会
                       ↑                 ↑                 ↑
              现金与风险余量      新证据、近期与长期记忆      历史经验

成交与账户变化 → 时点/来源/账本核对 → 已成熟的净回报 → 更新相应经验
```

观察行情通常不需要下单。先做不占用交易资本的观察与影子评估；只有确实需要执行信息时，
才考虑受预算约束的小额试探。影子收益不是实际赚到的钱，且其成交与成本假设必须单列。
这种区别是市场任务对生物类比的必要修正。

### 内部状态要改变决策，而不只是增加输入列

工程状态包括现金流动性、持仓集中度、允许的风险余量和已发生的回撤。
这些量首先决定动作是否可行，再研究它们是否应调节进入门槛、持续倾向或记忆读取。
同样的行情但不同的账户约束，是检验状态是否真的起作用的配对测试。

“饥饿”与“亏钱”没有生物学上的等价关系。首版不引入利润目标缺口驱动的冒险；
风险余量不足时缩小有成本的探索空间。这个方向是金融约束的工程选择，
不是从饥饿果蝇的行为直接推导出来的。

### 持续与退出需要独立的控制逻辑

将进入后的一段行为视为一个可以持续、也可以被中断的决策过程。
退出依据包括新证据、继续持有的预期价值、切换成本与硬性账户约束。
要检验它能否同时减少对短暂噪声的过度反应，以及在机会真正恶化时及时退出。
单纯减少换手并不证明机制有效，永远持有也可能做到。

数学上的工程桥梁是 options / 半马尔可夫决策过程（E9），其中 option 指持续性策略，
不是金融期权。这不是新提出的强化学习框架，也不是果蝇使用 TD 算法的生物证据。
交易作为有成本的序贯控制问题已有直接强化学习工作（E10），需纳入相关研究与基线。

### 记忆的生物时间尺度不能代替跨期回报

E7 的作者代码适合作为记忆模块的复现起点。先保留其原实验任务、反馈结构和双向可塑性，
复现指定的短期/长期记忆现象；再单独说明交易适配改变了哪些部分。
两个独立滑动平均不能直接称为该回路的复现。

交易适配中，近期经验可以快速改变判断，长期经验只接受已经可用、可归属且记账正确的
结果；盈利和亏损都应进入学习。是否形成长期记忆不能由“结果是否正面”决定。
线索强弱是观测或预测，不额外产生一次虚构的金钱奖励。

与此同时，必须修正旧模型的跨期目标。候选的工程目标为：

```text
r_t = log(W_(t+1) / W_t)
G_(t,τ) = Σ[k=0..τ-1] γ^k r_(t+k) + γ^τ V(b_(t+τ), h_(t+τ))
```

W 为扣除实际发生的费用后的账户财富；b 是仅由过去观测形成的市场信息状态，
h 是账户状态；τ 是本次持续行为的时长。区间费用只扣一次，终点价值在终止状态为零。
有限周期、γ=1 时回报累加对应终点对数财富；最大化期望对数财富与最大化期望金额
不是同一个目标，需在实验协议中明确。折扣选择也不能默默改变报告的优化目标。
首版使用正财富、无杠杆的可行账户；破产边界另作明确终止规则，不用任意截断掩盖。

这是待实现的长期回报定义，尚非现有实现。学习只能在相应反馈成熟后使用这些项，
不能用未来收益决定当前动作。慢记忆、延迟缓冲和 eligibility trace 本身均不能保证
跨动作信用分配正确；“建仓先付费、持有后获益”的反例必须单独通过。

## 我们的 fin-skills 放在哪里

已有接口适合承担输入、反馈与评估约束，而非代替神经控制器：

- `get("assert_causal")`：检查特征构造在所测扰动下是否使用未来数据；通过一次检查
  不代表全部时序问题都已排除。
- `Fact` / `Timeline` 与 `get("synthesis_integrity")`：检查合成事实的可用时点、
  来源链及未记录的来源冲突。它不自动证明市场信息真实，也不独立核算交易收益。
- 独立的成交、现金与持仓账本：核对进入学习的净反馈及最终评分。输入审计、反馈核算、
  最终评分的职责要分开，避免评估答案泄漏到控制器。
- `TrialLedger`：预先记录所有实验与对照，失败试验也保留。

反馈状态应区分：尚未到达、已到达但无效、已到达且有效。
无效反馈不更新；未到达的排队等待；有效亏损必须更新。
“甜但没营养”的对应，是有效反馈证明机会未兑现价值，不能泛化为丢弃一切负面结果。
这套验证机制是我们的工程设计，不声称果蝇存在金融数据审计回路。

## 最小研究顺序与否证条件

先做 E7 的原模型复现，再实现 **持续/退出控制与多时间尺度记忆** 的最小交易适配。
账户硬约束从开始就保留；重访记忆及更复杂内部状态门控通过后续独立消融加入，
避免一次堆入所有生物概念后无法定位作用。

| 已知答案的任务 | 必须观察到什么 | 什么结果会否定当前设计 |
|---|---|---|
| 先付进入成本、后续持有才获益 | 在完整周期目标下正确评价进入；与可计算最优解比较 | 仍因第一段损失长期拒绝有利进入 |
| 强线索，但毛收益不足以覆盖成本 | 从已成熟的负净回报中降低该机会的价值 | 因线索强或过去短期奖励而持续偏好净亏损机会 |
| 短暂噪声与真实条件变化分开出现 | 测量错误退出和真实变化后的退出延迟 | 只靠永远持有降低换手，或只是频繁切换 |
| 同一外部路径、不同账户余量 | 满足各自约束；量化状态门控的额外作用 | 亏损后自动增加风险，或门控不优于普通约束策略 |
| A→B→A 与反复价值反转 | 在可辨识条件下重新利用旧经验，保持可塑性 | 依赖隐藏状态标签，或重复反转后学习能力衰竭 |

还需设置无预测信息的负对照，防止把任何随机环境都设计成有利于候选模型。
最优解或隐藏状态只供独立评估器使用。任务参数、随机种子与成功判据在比较前冻结，
不能根据候选结果反复修改任务来让它胜出。

对照至少应包含普通持续性策略/层次强化学习、带相同快慢记忆的非生物控制器，
以及去掉状态门控、去掉记忆交互等消融。它们使用相同信息、动作可行域、成本、
奖励目标和可比调参预算。否则无法区分效果来自普通层次控制，还是所选果蝇机制。
同时报告净财富、风险、换手、退出行为、适应速度和重复学习稳定性。

已有 ECB 样本已经用于开发，只能继续作为开发材料，不能重新命名为未见测试集。
通过机制测试后，另行冻结新的市场评估协议。本轮不追加一轮历史收益调参。
后续 Beacon 的源代码、缓存、临时文件、调度日志和结果全部放在
`/beacon-projects/radfm/wy891/` 下的新实验目录，不写 Beacon HOME。

能够提出的研究假设是：**在有切换成本、反馈延迟和条件变化的任务中，资源状态调节的
持续/退出与可验证反馈驱动的多时间尺度记忆，是否改善适应和控制？**
是否具备金融收益优势、相对现有方法是否构成新贡献，都需要上述对照，当前没有答案。
