# 果蝇控制器架构审计（2026-09-21）

结论：v2/v3 的自定义架构有需要修正的问题。已有结果只能评价这些实现，
不能作为“果蝇蘑菇体不适合交易”的证据。之前先加账户特征、再比较净收益的顺序不充分：
应该先验证学习目标和持续适应能力。账本正确、时序正确，不代表控制器的学习目标正确。

本轮没有修改 v2/v3 模型，也没有筛选新的盈利参数。诊断脚本是
`benchmarks/verified_memory/audit_architecture.py`。Beacon 作业 `1614760` 已完成，

## 1. 已证实：单区间奖励与持续持仓目标错配

代码：`fly_v3.py:192` 关闭上一动作区间；`:226-227` 将该区间收益交给
`fly_v2.py:78-79`，目标是 `clip(reward / 0.01) - prediction_at_choice`。
没有后续状态价值、完整持仓收益或跨动作的回报传播。

当前动作会改变后续的持仓和交易成本，因此这个持续账户是顺序决策问题。
目前的学习仍是预测当前一个区间的结果。原始 KC 活动的保存和衰减解决的是
“延迟到达的反馈归属哪个观测”，没有解决“后续 HOLD 的收益应该怎样评价先前建仓”。
单区间目标可以是有意选择的短视策略，但不足以支持当前长期账户控制目标。

诊断是明确构造的两阶段任务：建仓先损失 0.2%，随后强制持有获得 0.8%，
全程复合收益为 0.5984%；现金收益为零。以相同电路和强制平衡的动作样本学习，
五个初始化下，当前区间目标都将建仓估值学成约 -0.1984，低于现金的 0；
完整过程收益目标将其学成约 +0.5935。数值为缩放后的价值，不是实际收益率。

这是学习目标的反例，不是完整交易模拟，也不是新算法的盈利实验。
对照直接提供已成熟的完整过程收益，仅用来定位错误；尚未实现新的市场信用分配机制。

## 2. 已证实：截断改变收益排序

代码：`fly_v3.py:227` 的收益缩放接上 `fly_v2.py:78` 的截断，实际将超过
正负 1% 的区间收益分别压到正负 1。同方向不同大小的尾部结果因此无法区分。

枚举反例：十次结果中，四次 +4%、六次 -1%，平均原始收益 +1%；
当前学习目标的均值却为 -0.2，低于现金的 0。这不是单纯改变单位。
它可以被定义为某种有界效用，但之前没有把这种效用与报告的净收益目标区分清楚。

只读检查旧 v3 的五个 ECB 轨迹：共 5,300 次已应用更新，655 次原始收益绝对值
超过 1%，实际触发截断。按初始化 11/23/37/53/71，次数为 144/90/135/123/163。
这些更新包含预热和评估阶段，不能解读成 655 个独立市场事件。
改变截断是否改善历史表现尚未做因果实验。

## 3. 已证实的压力测试缺陷：奖惩反转会消耗两侧突触

代码：`fly_v2.py:94-100`。正误差只削弱 avoidance，负误差只削弱 approach，
所有权重另以固定小步长恢复到 0.5。反复改变同一线索的目标时，两侧可用权重
均会减少；全局慢恢复不保证恢复学习容量。

使用原样电路、固定同一输入、每阶段 200 次更新，在 +1/-1 之间交替 24 阶段。
五个初始化中，最初两阶段末的平均绝对误差约 0.0041，最后两阶段约 0.70。
最后目标为 -1，输出只到约 -0.30，活跃 approach 权重均值降到 0。
之前的一次反转任务与权重有限性测试没有覆盖这种反复适应失败。

限制：这不是 ECB 亏损原因的证明。旧 v3 的五个 ECB 运行最终精确触底比例均为 0；
这也不是全程最小权重或近边界占比的记录。因此目前只能确认压力条件下的缺陷，
不能宣称市场运行发生了同样的耗尽。

## 4. 其他架构缺口：来源与证据范围

- 本实现把固定随机扩展、top-k、成对读出、标量误差、单边削弱、背景恢复、
  延迟缓冲和 epsilon 探索组合起来，是自定义近似。它不是任一原论文的精确复现，
  也没有使用真实全脑连接组。稀疏编码和易分类线索任务通过，不足以验证整套组合。
- Shen 等人的算法假设输入已去噪且具有可区分特征；论文明确把表征学习排除在主要目标外。
  当前价格特征直接拼接账户特征后进入随机投影，尚未证明它们能提供所需的交易信息。
  目前没有证据足以断言“账户特征压住了行情”，不能把这个猜测当成原因。
- 动作由固定列表示，不按候选组合及其后果编码。在现金状态，HOLD、cash、halve
  的经济效果相同，却分别学习；等权和逆波动在相同波动时也可重合。脚本验证了这个例子。
  这是样本利用率的限制，不是账本错误，也尚未量化其市场影响。
- 合成序列可预测，不等于当前观测、五日决策周期、固定专家动作能利用该信息。
  需要专门构造观测可辨、动作可达、收益答案已知的控制任务。

原始来源（本轮重新查阅）：

- [Shen 等：Algorithmic insights on continual learning from fruit flies](https://arxiv.org/html/2107.07617v2)：
  输入预处理、稀疏编码与部分冻结；属于关联/持续学习算法，不能直接替代持续账户控制。
- [Bennett 等：Learning with reinforcement prediction errors in a model of the Drosophila mushroom body](https://pmc.ncbi.nlm.nih.gov/articles/PMC8105414/)：
  研究强化预测及其电路和可塑性，并讨论受约束模型的学习限制；原任务是多选项奖励学习。
  论文提出的完整规则不能由我们这个只削弱一侧的更新自动代表。

## 修正顺序与验收条件

1. 保留蘑菇体稀疏关联记忆，先明确优化的是净财富、风险效用还是区间收益。
   明确跨期价值更新（例如一致的 TD 或完整过程回报）、成交时间和终止条件，
   不把记忆缓冲等同于跨期信用分配。移除未声明的收益截断，或明确其效用含义。
2. 选择一套有明确方程的可塑性模型，单独复现其学习行为；任何恢复/增强机制均需
   标注是文献规则还是工程扩展。先通过长期重复奖惩、反转、保留和遗忘任务。
3. 在观测可辨、动作可达的已知答案市场中，验证跨期收益、费用、不交易与重新入场。
   同一输入下，与线性/稠密控制器比较，确认差异来自记忆结构而非奖励或环境改变。
4. 上述条件满足后再做冻结设置的市场评估；旧 ECB 数据继续只作开发集。
   即使修正成功，也不预先承诺盈利或优于其他结构。

本轮结束点是完成架构诊断。没有把修正建议报告成已实现或已验证的 v4。
