# 开源决策模型运行记录：2026-09-23

Laya 英文版、多语言版，以及 Kev-0.8B、Kev-4B 已在 Beacon 使用真实本地权重
完成库接口验证。`create_model("laya", ...)` 和 `create_model("kev", ...)` 可以
执行结构化决策，并通过 `model.rerank` 接入内置 `RAGPipeline`。没有使用 TypeSafe
API key。库提供适配器；模型权重和上游运行时仍由用户单独准备。

Kev 验证设备为 NVIDIA L40S，运行环境为 torch 2.8.0、transformers 5.17.0、
peft 0.21.0，使用 bfloat16。上游日志显示线性注意力和因果卷积使用 PyTorch
参考实现，未安装专用加速内核。因此本轮耗时不能支持速度优势主张；首个请求
还包含加载开销。两种模型都顺序运行，未做独立重复延迟测量。

这些测试使用公开编写的短请求与合成片段，证明本地模型、返回契约和 Pipeline
接线可以工作。它们不能证明金融正确率、置信度校准或优于现有模型。
适配器只对四位小数舍入范围内的误差作显式归一化，同时保存原始响应；超出
范围的错误继续拒绝。未通过缩短测试输入或替换预测掩盖早期失败。

## 公开技能路由比较

已冻结 `evals/queries.jsonl` 中全部 108 道公开回归题。每题由同一 BM25 索引
召回前三个技能，保留完整名称与描述；决策器选择其中一个。候选顺序先按固定
种子打乱，再反转，以检查位置依赖。英文和中文分别报告。

Kev 作业 1653612、Laya 作业 1653613 的每个模型使用相同输入，每题两种顺序。
推理目录不包含目标标签；先固定响应与哈希回执，再在本地用原始标签评分。
所有计划题目都保留，超长拒绝和其他错误计入分母，不静默使用 BM25 兜底。
这套题在历史开发中已公开使用，结果只表示回归表现；不证明未见任务泛化，
也不测量实际工具执行或最终金融答案。

两项作业均为 COMPLETED / 0:0，所有模型—题目记录完整，哈希核对后才评分。
调度完成表示完整记录了响应或拒绝，不等于所有模型都成功推理。

| 方法 | 固定打乱顺序：正确 / 计划 | 反转顺序：正确 / 计划 | 两种顺序均成功 | 换序后决策变化 |
|---|---:|---:|---:|---:|
| BM25 首位 | 76/108 | 不适用 | 不适用 | 不适用 |
| Kev-0.8B | 45/108 | 50/108 | 108 | 36 |
| Kev-4B | 79/108 | 82/108 | 108 | 24 |
| Laya 英文版 | 无有效预测；108 次拒绝 | 无有效预测；108 次拒绝 | 0 | 无法估计 |
| Laya 多语言版 | 无有效预测；108 次拒绝 | 无有效预测；108 次拒绝 | 0 | 无法估计 |

BM25 前三名包含正确技能的题目为 100/108，所以重选候选本身无法解决其余八题。
Kev-4B 在固定打乱顺序下修正了 BM25 的 12 个错误，同时把九个原本正确的选择改错；
反转顺序下分别为 14 个和八个。改善幅度有限，且存在选项位置依赖，不能宣称稳定优于
BM25。题集中只有两道中文题，不据此判断中文能力。

Laya 的全部 432 次调用均在推理前被输入完整性检查拒绝。固定上游实现会把每个选项
文本限制为 48 tokens，还对问题头和总输入施加预算；完整技能描述无法原样保留。
这是本协议与模型输入预算不兼容，不能写成“Laya 准确率为零”。本轮没有看过结果后
缩短描述重跑，也没有解除截断检查。

**采用决定：** BM25 保持默认。Kev-4B 保留为可选路由增强，后续独立金融任务比较
继续带 BM25 对照与位置稳定性检查；Kev-0.8B 不设为默认。两个 Laya 版本保留短选项
决策和短片段评分接口，其 RAG 接入已跑通，具体任务质量仍需另外测量。
