\section{Conclusion}
\label{sec:conclusion}
\vspace{-0.08cm}
We presented \textbf{\texttt{fin-skills}} alongside an external counterfactual audit protocol and a checked delayed-feedback interface for financial AI agents. Unifying four empirical pillars---artifact-bound code self-repair ($98.3\%$ \texttt{Pass@3} on \texttt{FinGuardBench-60} after resolving Beacon \texttt{C0--C3} harness bottlenecks), progressive skill routing ($98.91\%$ token reduction and $64/64$ valid autonomous FX allocations), point-in-time credibility gating across \KOLPredRows{} timestamped predictions from \KOLTotalAccounts{} bilingual KOLs ($\Delta\text{Daily IC} = \KOLPairedDiffIC{}$), and 60-day rolling checked feedback for online mushroom-body memory ($\text{Daily IC } \KOLRollingDailyIC{}$)---demonstrates where and how executable financial verification eliminates backtest illusions and extracts statistically robust signal.

\section*{Limitations}
\label{sec:limitations}
\vspace{-0.14cm}
We note four scope boundaries and extensions:
\begin{enumerate}\setlength{\itemsep}{0.5pt}\setlength{\parskip}{0pt}\setlength{\topsep}{1.5pt}
    \item \textbf{Host Sandboxing vs.\ Independent Scorer Isolation}: While the Beacon worker enforces Linux Landlock and seccomp filters to restrict filesystem access, network calls, and process creation, submitted Python code still executes within the check interpreter; formal adversarial holdout benchmarks require an independently isolated scoring process.
    \item \textbf{Price-Only Series vs.\ Information Asymmetry}: As demonstrated in our 64-decision autonomous ECB FX study (\S\ref{sec:autonomous_pillar}), valid tool execution ($43/43$ calls) on efficient price-only reference series does not automatically generate excess return over passive controls; positive predictive gains require point-in-time filtering of noisy alternative data (\S\ref{sec:realworld}).
    \item \textbf{Repair Horizon on Compact Models}: While frontier generalist and reasoning models achieve $100.0\%$ ($60/60$) compliance within three guard-guided repair rounds (\texttt{Pass@3}), compact $7\text{B}\text{--}8\text{B}$ models reach $91.7\%$ ($55/60$) at \texttt{Pass@3} on deeply nested multi-table lineage tasks, motivating deeper repair budgets (\texttt{Pass@5}) or AST patch templates.
    \item \textbf{Online Memory Autonomy}: While our mushroom-body feedback interface (\S\ref{sec:fly_pillar}) validates complete-episode log-wealth targets $G=\log(W_T/W_0)$ and rolling 60-day calibration lifts cross-sectional IC to $\KOLRollingDailyIC{}$, end-to-end joint training of entry, holding-duration, and exit policies across non-biological and biological memory controllers remains an active extension.
\end{enumerate}
