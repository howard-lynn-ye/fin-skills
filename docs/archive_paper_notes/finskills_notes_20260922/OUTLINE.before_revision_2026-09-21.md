## Central argument / 论文主线

Current Large Language Models (LLMs) exhibit an "illusion of success" in quantitative finance tasks. Because financial logic is rarely validated at the causal execution level, models easily generate code that executes without crashing but contains silent mathematical flaws (e.g., look-ahead bias, unadjusted survivorship bias, incorrect latency assumptions). 

We introduce **FACT (Financial Agent Causal Tester)**, an open-source framework packaged as `fin-skills`. FACT provides a dual-layer solution: a 129-skill Knowledge Base to explicitly inject domain constraints, and a 36-guard Executable Audit Engine to deterministically catch execution hallucinations. We shift the LLM evaluation paradigm from "does the code run?" to "is the research mathematically and causally sound?"

*当前大模型在量化金融中表现出的高成功率是“虚假的”。由于缺乏因果层面的执行验证，大模型极易生成表面能跑通、但内部充满静默数学错误（如未来函数、幸存者偏差）的代码。我们提出了 FACT（基于 fin-skills 库），通过 129 个领域知识规约和 36 个可执行审计守卫，将大模型的评测范式从“代码不报错”升级为“逻辑绝对严谨”。*

## Research questions / 研究问题

- **RQ1 — Knowledge Injection & Constraint Verification**: Can source-verified domain constraints (Agent Skills) effectively steer LLMs away from flawed default library behaviors?
  *领域知识规约能否有效纠正大模型由于预训练语料带来的错误代码默认行为？*
- **RQ2 — Executable Auditing**: Can a deterministic audit engine automatically catch and intercept "silent traps" (e.g., look-ahead bias) generated by LLMs without relying on LLM self-reflection?
  *基于确定性数学逻辑的审计引擎，能否在不依赖 LLM 自身反思的情况下，精准拦截模型生成的“静默陷阱”？*
- **RQ3 — The True Baseline of SoTA Agents**: How do current State-of-the-Art models truly perform when subjected to strict, leak-free financial verification?
  *在极其严苛的防伪审查下，现有的顶尖大模型（GPT-4o, Claude 3.5）的真实表现究竟如何？*

## Contributions / 贡献定位

1. **The FACT Knowledge Base (Agent Skills).** The first comprehensive, source-verified skill library mapping silent errors across the Python quant ecosystem (129 skills across 17 plugins). It serves as a rigorously curated context layer for LLMs.
   **量化防伪知识底座：** 业界首个梳理了量化生态中 129 种静默错误和踩坑指南的规约库，为大模型提供防伪背景知识。
2. **An Executable Audit Engine.** A deterministic guard system (36 unified guards) that automatically audits LLM-generated artifacts for causal leaks, cost plausibility, and testing contamination via mathematical pressure tests.
   **可执行审计引擎：** 包含 36 个防伪守卫的确定性系统，通过真实扰动测试拦截未来函数、盈亏成本等隐蔽错误。
3. **The FACT Leak Detection Benchmark & Empirical Audit.** A novel evaluation protocol demonstrating that while current LLMs generate syntactically correct code, their performance drastically degrades under logical integrity tests. We establish the first verified baseline for financial code generation.
   **因果打假 Benchmark 与实证评测：** 证明了现有大模型在未搭载防伪引擎时的成功是极其脆弱的，建立了金融代码生成的首个真实基线。

## Section Outline / 正文结构规划

### 1. Introduction / 引言
- **The Problem:** The disconnect between software execution success and scientific validity in AI agents. Financial agents boast high Sharpe ratios that are often products of subtle look-ahead bias or library default errors (e.g., `vectorbt` filling at signal's close).
- **The Solution:** We propose **FACT**, an agentic verification ecosystem. 
- **Contributions:** Outline the Knowledge Base, Audit Engine, and Empirical Benchmark.

### 2. Related Work / 相关工作
- **Financial LLMs & Agent Benchmarks:** Differentiate from generic coding benchmarks (HumanEval) and unverified trading benchmarks (StockBench, FinGPT) by emphasizing causal execution integrity.
- **Tool-Use Verification:** Position FACT against standard code-execution verifiers (which only check for syntax/runtime errors) by highlighting our deterministic financial logic guards.

### 3. The FACT Framework (`fin-skills`) / 框架设计
- **3.1 Source-Verified Knowledge Layer:** How the 129 `SKILL.md` documents are structured to override flawed LLM priors.
- **3.2 The Executable Audit Engine:** Detail the core mathematical guards. Highlight `assert_causal` (point-in-time perturbation to detect shifts) and `contamination_probe` (LLM pre-training cutoff vs. test data overlap).
- **3.3 Tool Integration & Agent Routing:** How the framework interfaces with agents via JSON/MCP schemas as an autonomous pipeline.

### 4. The Leak Detection Benchmark / 审计引擎有效性验证
- **Methodology:** A 1,565-day synthetic financial world with delistings, splits, and complex corporate actions.
- **Planted Defects Validation:** We implant 12 severe research defects (e.g., unadjusted splits, rolling window leaks) and demonstrate the FACT engine catches 100% of them with 0 false positives on clean baselines.

### 5. Empirical Agent Evaluation / 大模型打假实证 (Core Experiment)
- **Experimental Setup:** Compare SoTA models (GPT-4o, Claude 3.5 Sonnet) on financial code generation tasks.
- **Condition A (Unverified Python):** Models generate backtests natively. Results show dangerously high apparent success rates.
- **Condition B (FACT Audited):** LLM outputs are routed through the Audit Engine. 
- **Results:** The engine blocks a significant percentage of "successful" submissions, exposing the true, lower capability baseline of current models. The Knowledge Base is then shown to significantly improve the pass rate of valid submissions.

### 6. Discussion and Limitations / 讨论与局限
- The limitations of deterministic checks (e.g., unable to verify proprietary unstructured data).
- Generalization of the FACT paradigm (Causal Verification) to other high-stakes domains like healthcare or legal agents.

### 7. Conclusion / 结论
- FACT shifts the goalpost for autonomous agents from generating "executable code" to generating "verifiably correct research".
