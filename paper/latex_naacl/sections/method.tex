\section{External Counterfactual Audit Methodology}
\label{sec:method}

A core methodological principle of our study is that \emph{an evaluation harness must never grade agent submissions using the same library guards given to the agent}. We construct an independent ground-truth \textbf{Seeded Market Generator} (\path{benchmarks/agent_study/}) spanning 60 equities over 2017--2023 with four planted shortcuts: (i) a news feed stamped with the session it describes, (ii) an LLM sentiment score trained through 2020-12-31, (iii) a listing table exposing future delisting dates, and (iv) unadjusted split prices.

\paragraph{Honest Ceiling vs.\ \texttt{FinGuardBench-180}.}
Because the data-generating process is closed-form, trading true latent drift with a 1-day lag earns \textbf{Net Sharpe $1.63$}, whereas same-session news joins earn \textbf{Net Sharpe $71.5$}. Across \textbf{FinGuardBench-180} (\path{benchmarks/guard_bench_180.py}: 36 guards $\times$ 5 modalities including $\pm 10^{-6}$ boundary and compound traps), our guards achieve \textbf{100\% accuracy ($180/180$, $0$ false alarms)} in $1.89\text{ ms}$ median latency.

\paragraph{Four Black-Box Counterfactual Perturbations.}
Given any agent-submitted weight function $\mathbf{W} = f(\mathcal{D})$, our external oracle (\texttt{oracle.py}) measures four invariants without reading agent source code:
\begin{enumerate}
    \item \textbf{Future Redraw (\texttt{leakage\_\allowbreak rate}):} Redraw market paths after cut date $t_c$; compute the fraction of pre-cut weights $\mathbf{W}_{t \le t_c}$ that change across 3 redraws.
    \item \textbf{Single-Session Redraw (\texttt{same\_\allowbreak session\_\allowbreak rate}):} Redraw session $t$ alone and inspect $\mathbf{W}_t$, catching same-day post-close joins invisible to cut-date holdouts.
    \item \textbf{Input Scramble (\texttt{uses\_}$\langle\text{file}\rangle$):} Permute individual input tables to test causal reliance on contaminated features (\texttt{llm\_\allowbreak score.csv}).
    \item \textbf{Physical Clock Replay:} Withhold future sessions physically by feeding data day-by-day (\texttt{live\_\allowbreak replay.py}).
\end{enumerate}
