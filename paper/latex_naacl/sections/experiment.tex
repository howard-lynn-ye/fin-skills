\section{Experiments}
\label{sec:experiment}

We evaluate \texttt{fin-skills} across four interlocking experimental pillars designed so that each study answers the causal limitation exposed by the preceding one: \textbf{(I)} artifact-bound code verification and multi-round self-repair (\S\ref{sec:pilot}), \textbf{(II)} progressive skill routing and autonomous tool execution (\S\ref{sec:autonomous_pillar}), \textbf{(III)} point-in-time credibility gating on timestamped social predictions (\S\ref{sec:realworld}), and \textbf{(IV)} checked delayed-outcome feedback for online mushroom-body memory (\S\ref{sec:fly_pillar}).

\subsection{Pillar I: From Pilot \& Beacon \texttt{C0--C3} to \texttt{FinGuardBench-60} Self-Repair}
\label{sec:pilot}

\paragraph{The \PilotRuns{}-Run Opus/Haiku Pilot \& Beacon \texttt{C0--C3} Diagnosis.}
In an initial \PilotRuns{}-run exploratory pilot (\path{PILOT_RESULTS.json}), providing \texttt{fin-skills} reduced Claude Opus's mean absolute Sharpe reporting discrepancy by \textbf{\OpusReduction{}\%} ($\OpusBase{} \to \OpusLibrary{}$), whereas Claude Haiku's discrepancy expanded from $\HaikuBase{} \to \HaikuLibrary{}$ while citing unexecuted guards. To separate static guidance from executable checks on open-weight models (\texttt{Qwen2.5-Coder 7B/14B/32B}), we ran a 4-condition Beacon feasibility study (\texttt{C0 no\_library}, \texttt{C1 skills\_text\_only}, \texttt{C2 skills\_optional\_guards}, \texttt{C3 skills\_enforced\_guards}; \path{BEACON_FEASIBILITY_RESULTS.json}). In that initial batch (Appendix Table~\ref{tab:beacon_feasibility}), 14B achieved $2/3$ (\texttt{C0}), $2/3$ (\texttt{C1}), and $3/3$ (\texttt{C2}) acceptance ($\BeaconFourteenCTwoMeanTokens{}$ mean tokens), but $0/3$ under enforced audit \texttt{C3} ($\BeaconFourteenCThreeMeanTokens{}$ tokens) with $7$ ungradable submissions. Auditing those exact failure traces revealed four harness/interface defects rather than model reasoning impossibility: (i) \texttt{same\_session\_probe} multiplied \texttt{int64} \texttt{volume.csv} by float perturbations $\text{linspace}(0.7,1.3)$, throwing \texttt{LossySetitemError} inside \texttt{C3}; (ii) \texttt{oracle.py} called \texttt{pd.to\_datetime(result.index)} before promoting \texttt{"date"} columns, mapping \texttt{RangeIndex} to \texttt{1970-01-01}; (iii) \texttt{build\_task.py} omitted explicit index labels; and (iv) 32B \texttt{bfloat16} multinomial sampling overflowed across dual GPUs.

\paragraph{Post-Fix \texttt{FinGuardBench-60} \& Feedback Granularity (E5, E6, E9).}
Resolving those four harness defects (\path{tests/test_agent_study_priority1_fixes.py}) yields $0$ ungradable outputs across \texttt{FinGuardBench-60} (Table~\ref{tab:pilot}). Reading \texttt{SKILL.md} (\texttt{Cond B}) lifts compliance from $30.0\%$ to $70.0\%$ ($p=1.19\times 10^{-7}$), but adding 3 rounds of generic Python \texttt{Self-Debug} \citep{chen2023selfdebug} (\texttt{Cond B+}) stagnates at $71.7\%$ ($p=1.0$) because \textbf{$60/60$ ($100\%$) of silent financial leaks execute with Python exit code $0$} (\path{EXTENDED_ABLATIONS_E9_E12_RESULTS.json}). Conversely, binding \texttt{Bundle.check()} to the submission loop (\texttt{Cond C}) drives multi-round repair to $\mathbf{98.3\%}$ (\texttt{Pass@3}, $p=3.05\times 10^{-5}$ vs.\ \texttt{B+}), eliminating hallucinated citations ($0.0\%$) across all four model tiers (Fig.~\ref{fig:domain_scaling}b).

\subsection{Pillar II: Progressive Routing (E12) \& 64-Decision Autonomous Study}
\label{sec:autonomous_pillar}

A natural question is whether open-weight agents can autonomously discover and invoke \texttt{fin-skills} tools during sequential portfolio decision-making without prompt overflow. In Experiment~E12 (\path{run_extended_ablations_e9_e12.py}), concatenating all 129 \texttt{SKILL.md} files consumes $369{,}315$ prompt tokens and Top-3 TF-IDF chunk RAG ($9{,}042$ tokens) loses $28.3\%$ of required guards ($71.67\%$ recall), whereas our progressive manifest routing (\texttt{list\_algorithms} $\to$ \texttt{read\_skill} $\to$ \texttt{run\_algorithm}) requires only \textbf{$4{,}039$ tokens ($-98.91\%$, $0.007\text{ ms}$)} while preserving \textbf{100.0\% guard recall}.

Deploying this progressive action loop across 16 trials ($64$ sequential decisions on 2025 ECB FX reference rates; Table~\ref{tab:autonomous} and Appendix~\ref{app:autonomous}), Qwen2.5-Coder 7B and 14B completed \textbf{64/64 (100\%) valid final allocations} and executed \textbf{43/43 (100\%) model-selected tool calls} ($13$ by 7B across cross-sectional and volatility-targeted momentum; $30$ by 14B across Bollinger reversion and trend-following skills) with zero call errors. Crucially, Table~\ref{tab:autonomous} establishes an essential scientific boundary: on efficient, price-only FX reference series without external information asymmetry, calling standard price-based algorithms does not outperform no-library controls ($-3.984\%$ vs.\ $+0.100\%$ for 7B; $-3.783\%$ vs.\ $-3.324\%$ for 14B). This negative price-only finding directly motivates Pillar~III: \emph{where does \texttt{fin-skills}'s timestamp and credibility verification produce genuine predictive edge?}

\paragraph{Row-Level Timestamped Reversal \& Progressive Component Ablation (E11).}
Table~\ref{tab:kol} confirms that retail follower counts inversely track predictive skill in both markets ($3.96\times$ contrarian fan ratio in China, $1.54\times$ in the US). When evaluated across all \KOLTradingDates{} paired trading dates with strict \texttt{pred\_time $\le$ avail\_time $<$ open\_time} enforcement, \texttt{naive\_\allowbreak follower\_\allowbreak volume\_\allowbreak weighted} aggregation yields a negative mean daily cross-sectional Rank IC of \textbf{\KOLNaiveDailyIC{}}, whereas \texttt{pit\_\allowbreak kol\_\allowbreak credibility\_\allowbreak gated} achieves \textbf{\KOLGatedDailyIC{}}, establishing a statistically significant paired daily IC improvement of \textbf{\KOLPairedDiffIC{}} (5-day block-bootstrap 95\% CI $[+0.0074, +0.0728]$). Progressive component ablation on this exact \KOLPredRows{}-row ledger (Experiment~E11, Table~\ref{tab:e11_component}) shows monotonic gains across all five stages: from \texttt{Stage 0 Naive} ($\text{Daily IC } -0.0115$, $\text{MDD } -32.61\%$) and \texttt{Stage 1 DataQualityAuditor} ($\text{MDD } -28.03\%$), to \texttt{Stage 2 StockPredictabilityStratifier} ($\text{Daily IC } +0.0157$, $\text{MDD } -17.84\%$), \texttt{Stage 3 PIT KOLCredibilityRegistry} ($\text{Daily IC } +0.0273$, $\text{MDD } -16.75\%$), and \texttt{Stage 4 VolatilityAndExecutionGuards} ($\text{Daily IC } \mathbf{+0.0294}$).

\subsection{Pillar IV: Checked Delayed Feedback, Fruit-Fly Memory \& Regime Calibration (E10)}
\label{sec:fly_pillar}

Finally, we connect \texttt{fin-skills} to online learning by gating delayed episode outcomes before they update a fruit-fly mushroom-body memory architecture \citep{huang2024memory} (\path{benchmarks/verified_memory/}, Appendix~\ref{app:fly}). Rather than feeding raw one-step returns that suffer from clipping distortion and unverified timestamps, our feedback interface requires an episode to close and verifies interval continuity, \texttt{avail} timestamps, and source-lineage guards before computing complete-episode log-wealth $G = \sum_{t=0}^{T-1}\log(W_{t+1}/W_t) = \log(W_T/W_0)$.
