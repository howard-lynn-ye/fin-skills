\section{Experiment E1: Synthetic Defect Recall Across Random Seeds}
\label{app:e1}
In \path{benchmarks/guard_bench.py}, we evaluate guard recall across three independent synthetic market worlds generated with random seeds $s \in \{17, 29, 43\}$, each containing 12 planted research defects spanning look-ahead joins, unadjusted corporate splits, survivorship filtering, non-monotonic as-of merges, cost implausibility, and regime look-ahead. Across all three worlds, \texttt{fin-skills} achieved \textbf{100\% recall ($36/36$ total defects detected)}, \textbf{0 false alarms} across 400 clean control runs, and \textbf{0 runtime exceptions} (\path{benchmarks/GUARD_ROBUSTNESS.json}).

\section{Experiment E2: Three-Condition Open-Weight Scaffold \& Compliance Auditor}
\label{app:e2}
To strictly isolate whether agent improvements stem from passive prompt documentation or active runtime execution, we implement \path{benchmarks/agent_study/open_agent_runner.py}, which evaluates any OpenAI-compatible open-weight server (\texttt{Qwen2.5-\allowbreak Coder-\allowbreak 32B-\allowbreak Instruct}, \texttt{DeepSeek-V3}, \texttt{Llama-3.3-\allowbreak 70B-\allowbreak Instruct}) across three isolated conditions:
\begin{itemize}
    \item \textbf{Condition A (\texttt{no\_library}):} Task prompt and raw market CSVs only.
    \item \textbf{Condition B (\texttt{skills\_text\_only}):} Injects relevant \texttt{SKILL.md} guidance into context while physically blocking \texttt{fin\_skills.api} guard imports.
    \item \textbf{Condition C (\texttt{skills\_plus\_guards}):} Provides both \texttt{SKILL.md} text and executable guard tools with immutable runtime provenance logs (\texttt{guard\_\allowbreak execution\_\allowbreak trace.json}).
\end{itemize}
Our \texttt{ComplianceAuditor} cross-checks every guard name cited in the agent's final report against the runtime provenance log, flagging any cited guard that was not actually invoked on the submission outputs (\path{SCAFFOLD_VERIFICATION_REPORT.json}).
