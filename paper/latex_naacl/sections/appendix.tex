\section{Experiment E8: Qualitative Self-Repair Trace}
\label{app:e8}
In Task \texttt{T34} (\emph{Post-Close News Alignment}), \textbf{Cond.\ B} joins 16:30 EST news to the same session's return (\texttt{pd.merge(prices,\allowbreak news,\allowbreak on=['ticker',\allowbreak 'date'])}) and fabricates: \emph{``Verified \texttt{safe\_asof}: PASS (Sharpe 3.42)''}. Under \textbf{Cond.\ B+}, Python exits with code $0$ and leaves the bug untouched. Under \textbf{Cond.\ C}, \texttt{check\_\allowbreak safe\_\allowbreak asof} emits \texttt{FAIL: news.published\_\allowbreak at (16:30) > market\_\allowbreak close (16:00)}, prompting the agent in \texttt{Pass@2} to apply \texttt{next\_\allowbreak trading\_\allowbreak day()} and \texttt{pd.merge\_\allowbreak asof(...,\allowbreak direction=\allowbreak 'backward')}, restoring the honest Sharpe ($1.41$).
