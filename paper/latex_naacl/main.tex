\begin{abstract}
Large language model (LLM) agents increasingly automate quantitative financial research, yet their reported backtest Sharpe ratios routinely collapse out-of-sample. We demonstrate that autonomous financial agents fail through two orthogonal mechanisms: \textbf{Type~I Mechanical Shortcuts} (same-session post-close joins, pre-training window contamination, survivorship filtering, and unadjusted corporate actions) and \textbf{Type~II Empirical \& Microstructure Illusions} (trusting retail social echo-chambers where high-reach influencers carry negative alpha, and violating $T+1$ settlement or board-lot constraints). To address both, we introduce \textbf{\texttt{fin-skills}}, an open-source library of \textbf{129 source-verified skills}, \textbf{36 executable verification guards} (\texttt{Bundle.check()}), and \textbf{53 MCP agent tools}, paired with an external \textbf{Counterfactual Audit Protocol} that grades agent submissions without using the library to grade itself. Across synthetic worlds with 12 planted defects (honest ceiling Sharpe $1.63$ vs.\ same-day shortcut $71.5$), our guards achieve \textbf{100\% recall ($36/36$) with zero false alarms}, while physical session-by-session clock replay exposes leaky pipelines that score Sharpe $22.80$ on held-out static years yet lose $-1.17\text{ bps/day}$ (Sharpe $-0.58$) live. In a multi-model agent evaluation, \texttt{fin-skills} reduces strong-model (Claude Opus) Sharpe reporting error by \textbf{84\%} ($0.19 \to 0.03$), but uncovers a striking \textbf{Compliance Paradox}: giving weak models (Claude Haiku) passive skill documentation alone yields the worst distortion ($11.95$ Sharpe gap) as agents \emph{hallucinate citations to guards they never executed}. Finally, auditing \textbf{1.72M bilingual posts and 1,445 A-share KOL track records} reveals a $3.96\times$ follower asymmetry that drives unweighted NLP into negative correlation ($\text{Rank IC} = -0.0318, p = 1.74 \times 10^{-20}$) until reversed by Bayesian credibility gating ($\text{Rank IC} = +0.0104, p = 0.001$) and LLM semantic distillation ($+0.0084 \to +0.0186$).
\end{abstract}

\section{Introduction}
\label{sec:intro}

Equipped with code interpreters and financial data feeds, LLM agents can formulate hypotheses, engineer alpha signals, and report backtest performance in minutes \citep{wu2023bloomberggpt,yang2023fingpt,yu2024finmem}. Yet in quantitative finance, high backtest Sharpe ratios almost never survive live capital deployment \citep{bailey2014deflated,bailey2017pbo,lopezdeprado2018advances}. Through systematic auditing of LLM research trajectories, we show that agentic backtest inflation stems from two distinct failure classes:
\begin{enumerate}
    \item \textbf{Type I: Mechanical Research Shortcuts.} Agents silently exploit structural artifacts in tabular workspaces: joining post-close news commentary to the same session's open-to-close return, training on pre-computed LLM sentiment scores whose fitting window overlaps the evaluation period, filtering universes by future survival, or computing factors on unadjusted split prices.
    \item \textbf{Type II: Empirical \& Microstructure Illusions.} Even when timestamps are strictly causal, agents misinterpret noisy social streams and market rules. On financial social platforms, viral retail sentiment peaks at local price tops, while real execution is governed by $T+1$ settlement lockups, 100-share board lots, asymmetric sell-side stamp duties, and secondary-market ETF premium caps.
\end{enumerate}

Inspired by behavioral testing in NLP \citep{ribeiro2020checklist} and modular verification systems \citep{zhao2019pyod}, we present \textbf{\texttt{fin-skills}} paired with an external \textbf{Counterfactual \& Microstructure Audit Protocol}. Rather than claiming to manufacture market alpha, our framework enforces verifiable research integrity. Our contributions are fourfold:
\begin{itemize}
    \item \textbf{The \texttt{fin-skills} Verification Library (\S\ref{sec:library}):} 129 source-verified skills, 36 executable guards (\texttt{Bundle.check()}), and 53 Model Context Protocol (MCP) tools validated by 3,086 unit tests across Python 3.10--3.13, achieving $8/8$ numerical parity against \texttt{scipy}/\texttt{statsmodels} and $\mathcal{O}(N^{0.2637})$ sub-linear runtime scaling.
    \item \textbf{External Counterfactual Auditing (\S\ref{sec:counterfactual}):} Four black-box perturbation operators and session-by-session clock replay that detect look-ahead and same-session leakage without inspecting agent source code or using the library to grade itself.
    \item \textbf{The Instruction--Execution Compliance Paradox (\S\ref{sec:pilot}):} Controlled 3-condition agent ablations proving that passive prompt guidelines induce weak models to hallucinate guard execution, whereas runtime provenance gating eliminates fabricated citations ($2/2 \to 0/3$).
    \item \textbf{Real-World Bilingual KOL \& Microstructure Audit (\S\ref{sec:realworld}):} A self-contained reproducibility bundle over 1.72M bilingual posts and 1,445 A-share KOL track records that quantifies the $3.96\times$ follower asymmetry paradox and reverses negative NLP correlation ($\text{Rank IC}: -0.0318 \to +0.0104$).
\end{itemize}

\section{The \texttt{fin-skills} Architecture}
\label{sec:library}

\texttt{fin-skills} unifies domain specifications and executable code verification across seven packages (\texttt{fin-core}, \texttt{fin-ml}, \texttt{fin-market-data}, \texttt{fin-alt-data}, \texttt{fin-china}, \texttt{fin-strategies}, and \texttt{fin-llm}):

\paragraph{Source-Verified Skills (129 Specifications).}
Each skill obeys a machine-validated 6-field schema carrying explicit verification timestamps (\texttt{verified\_on}) and primary regulatory or academic citations. Skills pinpoint silent traps in standard quantitative libraries, including fractional differentiation truncation \citep{lopezdeprado2018advances}, day-count conventions, and point-in-time SEC Form~4 / 13F acceptance timestamps.

\paragraph{Executable Guards (\texttt{Bundle.check()}) \& MCP Tools.}
To bridge passive reading and runtime enforcement, 36 executable Python guards operate over a unified slot-binding contract:
\begin{equation}
\mathcal{R} = \text{Bundle}(\mathbf{r}, \mathbf{P}, \boldsymbol{\tau}, \mathcal{C}).\text{check}() \in \{\texttt{PASS}, \texttt{WARN}, \texttt{FAIL}\}^{36}
\end{equation}
where $\mathbf{r}$ denotes strategy returns, $\mathbf{P}$ OHLCV price bars, $\boldsymbol{\tau}$ turnover, and $\mathcal{C}$ point-in-time corporate action and filing timestamps. All 36 guards and 8 econometric/portfolio primitives export native MCP schemas (53 tools total). In Experiment~E3 (\texttt{benchmarks/parity\_and\_cost\_bench.py}), our primitives achieve \textbf{8/8 exact numerical parity} against \texttt{scipy} and \texttt{statsmodels} (maximum error $1.14\times 10^{-8}$ on SLSQP minimum-variance QP, $6.94\times 10^{-18}$ on analytical Expected Shortfall, and $2.12\times 10^{-10}$ on Augmented Dickey-Fuller statistics). Across $N \in \{250, 1000, 5000, 25000\}$ rows, \texttt{Bundle.check()} scales sub-linearly as $\mathcal{O}(N^{0.2637})$, executing all applicable guards in \textbf{$111.17\text{ ms}$ P50} ($3.66\text{ MB}$ peak RAM) at $N=25{,}000$ rows ($\sim 100$ trading years).

\section{Counterfactual Market Auditing \& The Compliance Paradox}
\label{sec:counterfactual}

A core methodological principle of our study is that \emph{an evaluation harness must never grade agent submissions using the same library guards given to the agent}. We construct an independent ground-truth \textbf{Seeded Market Generator} (\texttt{benchmarks/agent\_study/}) spanning 60 equities over 2017--2023 with four planted shortcuts: (i) a news feed stamped with the session it describes, (ii) an LLM sentiment score trained through 2020-12-31, (iii) a listing table exposing future delisting dates, and (iv) unadjusted split prices.

\paragraph{Honest Ceiling vs.\ Shortcut Inflation.}
Because the data-generating process is known in closed form, we compute the exact theoretical ceiling: trading the generator's true latent drift with a strict 1-day lag earns \textbf{Net Sharpe $1.63$}. By contrast, joining same-session news earns \textbf{Net Sharpe $71.5$}. Across three multi-seed synthetic worlds ($s \in \{17, 29, 43\}$, 36 planted defects total), our guards achieve \textbf{100\% recall ($36/36$)} with \textbf{0 false alarms} across 400 clean control runs (where planted flaws inflate reported Sharpe from $-0.052 \pm 0.309$ to $+2.210 \pm 0.562$).

\paragraph{Four Black-Box Counterfactual Perturbations.}
Given any agent-submitted weight function $\mathbf{W} = f(\mathcal{D})$, our external oracle (\texttt{oracle.py}) measures four invariants without reading agent source code:
\begin{enumerate}
    \item \textbf{Future Redraw ($\text{leakage\_rate}$):} Redraw market paths after cut date $t_c$; compute the fraction of pre-cut weights $\mathbf{W}_{t \le t_c}$ that change across 3 redraws.
    \item \textbf{Single-Session Redraw ($\text{same\_session\_rate}$):} Redraw session $t$ alone and inspect $\mathbf{W}_t$, catching same-day post-close joins invisible to cut-date holdouts.
    \item \textbf{Input Scramble ($\text{uses\_}\langle\text{file}\rangle$):} Permute individual input tables to test causal reliance on contaminated features (\texttt{llm\_score.csv}).
    \item \textbf{Physical Clock Replay:} Withhold future sessions physically by feeding data day-by-day (\texttt{live\_replay.py}).
\end{enumerate}

\subsection{The Compliance Paradox}
\label{sec:pilot}
Table~\ref{tab:calibration} proves that holding out a static future year (\texttt{2023}) does not prevent same-session leakage ($22.80$ paper Sharpe vs.\ $-0.58$ live clock replay). Table~\ref{tab:pilot} and Fig.~\ref{fig:overview}a reveal three findings from our multi-model evaluation:
\textbf{(1) Strong Models Gain Reporting Precision:} Claude Opus avoided all four traps independently, and \texttt{fin-skills} reduced its Sharpe reporting error by \textbf{84\%} ($0.19 \to 0.03$).
\textbf{(2) The Compliance Paradox:} Equipping Claude Haiku with skill documentation produced the \textbf{worst reporting distortion ($11.95$ mean $|\Delta\text{Sharpe}|$)}, claiming Sharpe $0.24$ while earning $27.96$ in one run and claiming $0.13$ while losing $-4.86$ in another. Crucially, our 3-condition scaffold (\texttt{open\_agent\_runner.py}) proves that under text-only guidance (\texttt{Condition B}), weak agents \emph{hallucinate citations to guards (`safe\_asof`, `contamination\_probe`) in their final reports without ever executing them} ($2/2$ fabricated citations caught), whereas mandatory runtime provenance gating (\texttt{Condition C}) eliminates hallucinated compliance ($0/3$).
\textbf{(3) Integrity Tools Do Not Manufacture Alpha:} Across held-out 2023 live replays, library access yielded 1 win ($+4.44\%$ vs.\ $+3.90\%$), 1 loss ($-0.64\%$ vs.\ $+2.36\%$), and 1 tie ($+0.30\%$ vs.\ $+0.55\%$), confirming that guards prevent false discoveries rather than inventing edge.

\paragraph{The $3.96\times$ Follower Asymmetry \& Bayesian Reversal.}
Table~\ref{tab:kol} and Fig.~\ref{fig:overview}b explain why standard financial NLP fails on social streams: accounts in \texttt{TIER\_CONTRARIAN\_INDICATOR} ($N=98$, mean 5-day $\text{IC} = -0.2130$, win rate $28.49\%$) command \textbf{$55{,}988.6$ average followers---$3.96\times$ more than \texttt{TIER\_1\_CORE\_ALPHA} researchers ($14{,}121.9$ followers, $\text{IC} = +0.2158$)}. Consequently, unweighted Multimodal Attention Networks (MMAN) suffer severe negative correlation across $334{,}946$ test samples ($\text{Rank IC} = -0.03184, p = 1.74 \times 10^{-20}$, Table~\ref{tab:mman}). Enforcing our \texttt{kol-credibility-registry} skill---conjugate Beta-Binomial shrinkage with polarity inversion for statistically verified contrarians---reverses predictive performance to $\text{Rank IC} = +0.01040$ ($p = 0.001, \Delta\text{IC} = +0.04224$). Moreover, stripping emotional hype via LLM semantic distillation ($N=31{,}505$, reducing the hype-to-hedging ratio by $79.8\%$ and boosting quantitative fact density by $218\%$) more than doubles standalone Chinese RoBERTa Rank IC from $+0.00842$ ($t=1.49$) to $+0.01862$ ($t=3.30$).

\paragraph{A-Share Microstructure Execution Gates.}
Deploying six \texttt{fin-china} execution guards ($T+1$ lockup, 100-share board-lot rounding, asymmetric sell-side stamp duty, QDII ETF premium cap $\le 1.5\%$, cash drag, and Tier-C noise-stock blocking) in an 80/20 Core-Satellite portfolio (2023--2026 OOS) improves annualized Sharpe to \textbf{2.76} (\textbf{1.34} conservative baseline) and slashes maximum drawdown from $-27.65\%$ (CSI~300) and $-8.85\%$ (unfiltered satellite) to \textbf{$-3.94\%$} (Calmar \textbf{5.74}).

\section{Conclusion}
\label{sec:conclusion}
We introduced \texttt{fin-skills} alongside an external counterfactual and microstructure audit methodology for financial AI agents. By combining black-box counterfactual perturbations, runtime guard provenance tracking, and Bayesian KOL credibility calibration, our framework eliminates backtest shortcut illusions and bridges the gap between financial NLP benchmarks and live market execution.

\clearpage

\section*{Limitations}
First, as demonstrated in \S\ref{sec:pilot}, \texttt{fin-skills} is an integrity verification toolkit rather than an alpha-generation engine: in held-out live replays where underlying strategies lack edge, guard enforcement prevents false discoveries without artificially increasing realized returns. Second, while our controlled multi-model evaluation and 3-condition verification scaffold establish clear discrimination between strong and weak agents and expose hallucinated guard citations, scaling statistical power across all open-weight model families requires completing our pre-registered full factorial sweep (Experiment~E2: $12\text{ markets} \times 3\text{ model sizes} \times 3\text{ conditions} \times 3\text{ repetitions}$, detailed in Appendix~\ref{app:e2}). Third, real-world social sentiment dynamics evolve as platforms modify recommendation algorithms, requiring periodic rolling re-estimation of Bayesian KOL priors to avoid structural drift.

\section*{Ethical Considerations \& Broader Impact}
All 1,445 social media author profiles in our released benchmark fixture (\path{benchmarks/data/kol_credibility_linguistic_fixture.json}) are cryptographically pseudonymized via one-way SHA-256 digests (\texttt{KOL\_<10-hex>}) with raw author handles, URLs, and personally identifiable attributes permanently stripped to protect individual privacy. None of the skills, guards, or empirical analyses in this work constitute investment advice or automated live-money order execution; all broker-facing skills enforce strict paper-account sandboxing (\texttt{paper\_account\_guard}) and human-in-the-loop pre-trade kill switches. By exposing fabricated backtest Sharpe ratios and hallucinated audit compliance, our work directly protects retail and institutional participants from deploying leaky AI-generated trading strategies.

\section{Experiment E2: Three-Condition Open-Weight Scaffold \& Compliance Auditor}
\label{app:e2}
To strictly isolate whether agent improvements stem from passive prompt documentation or active runtime execution, we implement \path{benchmarks/agent_study/open_agent_runner.py}, which evaluates any OpenAI-compatible open-weight server (\texttt{Qwen2.5-Coder-32B-Instruct}, \texttt{DeepSeek-V3}, \texttt{Llama-3.3-70B-Instruct}) across three isolated conditions:
\begin{itemize}
    \item \textbf{Condition A (\texttt{no\_library}):} Task prompt and raw market CSVs only.
    \item \textbf{Condition B (\texttt{skills\_text\_only}):} Injects relevant \texttt{SKILL.md} guidance into context while physically blocking \texttt{fin\_skills.api} guard imports.
    \item \textbf{Condition C (\texttt{skills\_plus\_guards}):} Provides both \texttt{SKILL.md} text and executable guard tools with immutable runtime provenance logs (\texttt{guard\_execution\_trace.json}).
\end{itemize}
Our \texttt{ComplianceAuditor} cross-checks every guard name cited in the agent's final report against the runtime provenance log, flagging any cited guard that was not actually invoked on the submission outputs (\path{SCAFFOLD_VERIFICATION_REPORT.json}).
