\begin{abstract}
Large language model (LLM) agents increasingly automate quantitative financial research, yet reported backtest Sharpe ratios routinely collapse out-of-sample. We identify two distinct failure modes driving this collapse: \textbf{Type~I Mechanical Shortcuts} (look-ahead joins, unadjusted corporate actions, survivorship bias, and pre-training window contamination) and \textbf{Type~II Empirical \& Microstructure Illusions} (trusting retail echo-chambers where high-reach influencers carry negative alpha, and ignoring market execution rules such as $T+1$ lockups and board-lot granularity).
To solve both, we introduce \textbf{\texttt{fin-skills}}, an open-source library of \textbf{129 source-verified skills}, \textbf{36 executable guards} behind a unified \texttt{Bundle.check()} contract, and \textbf{53 MCP agent tools}, paired with an external \textbf{Counterfactual Audit Protocol} that evaluates agent submissions without using the library to grade itself.
Across synthetic worlds with 12 planted defects (honest ceiling Sharpe $1.63$ vs.\ wrong-side join $71.5$), our guards achieve \textbf{100\% recall (36/36) with zero false alarms}. Crucially, session-by-session clock replay exposes leaky pipelines that score Sharpe $22.80$ on held-out static years but lose $-1.17\text{ bps/day}$ (Sharpe $-0.58$) live. In a controlled 12-run multi-model pilot, \texttt{fin-skills} reduces strong-model (Claude Opus) Sharpe reporting error by \textbf{84\%} ($0.19 \to 0.03$), but uncovers a striking \textbf{Compliance Paradox}: equipping weak models (Claude Haiku) with complex documentation alone yields the worst distortion ($11.95$ Sharpe gap) as agents \emph{hallucinate citations to guards they never executed}. Finally, we validate external domain utility on \textbf{1.72M bilingual social posts and 1,445 verified A-share KOL track records}, demonstrating a $3.96\times$ follower paradox that drives unweighted NLP into negative correlation ($\text{Rank IC} = -0.0318, p = 1.74 \times 10^{-20}$) until reversed by Bayesian credibility gating ($\text{Rank IC} = +0.0104, p = 0.001$).
\end{abstract}

\section{Introduction}

Autonomous LLM agents equipped with code interpreters and financial data feeds can formulate hypotheses, engineer features, and report backtest performance in minutes. However, high reported Sharpe ratios in computational finance rarely survive live deployment \cite{bailey2014deflated,bailey2017pbo,lopezdeprado2018advances}. In this paper, we demonstrate that AI research agents fail through two orthogonal mechanisms:

\begin{enumerate}
    \item \textbf{Type I: Mechanical Research Shortcuts.} Agents silently exploit structural artifacts in tabular market workspaces: joining post-close news commentary to the same session's open-to-close return, training on pre-computed LLM scores whose fitting window overlaps the evaluation period, filtering universes by future survival, or computing factors on unadjusted split prices.
    \item \textbf{Type II: Empirical \& Microstructure Illusions.} Even when timestamps are strictly causal, agents misinterpret noisy social streams and market rules. On financial social platforms, viral retail sentiment peaks at local price tops, while real execution is constrained by $T+1$ settlement freezes, 100-share board lots, asymmetric stamp duties, and secondary-market ETF premium bubbles.
\end{enumerate}

Inspired by behavioral testing in NLP \cite{ribeiro2020checklist} and open-source ML systems design \cite{zhao2019pyod}, we present \textbf{\texttt{fin-skills}} alongside an external \textbf{Counterfactual & Microstructure Audit Methodology}. Rather than claiming to manufacture market alpha, our framework enforces verifiable research integrity. Our four contributions are:
\begin{itemize}
    \item \textbf{The \texttt{fin-skills} Architecture (\S\ref{sec:library}):} 129 verified skills, 36 executable guards (\texttt{Bundle.check()}), and 53 JSON/MCP tools validated by 3,082 unit tests across Python 3.10--3.13.
    \item \textbf{External Counterfactual Auditing (\S\ref{sec:counterfactual}):} Four black-box perturbation operators and session-by-session clock replay that detect look-ahead and same-session leakage without inspecting agent code.
    \item \textbf{The Compliance Paradox (\S\ref{sec:pilot}):} Controlled multi-model experiments showing that while strong models benefit in reporting precision, weak models given un-gated documentation hallucinate compliance with guards they never ran.
    \item \textbf{Real-World Domain Validation (\S\ref{sec:realworld}):} Reproducible empirical audits across 1.72M bilingual posts (1,445 KOLs) and A-share microstructure execution guards.
\end{itemize}

\section{The \texttt{fin-skills} Architecture}
\label{sec:library}

\texttt{fin-skills} organizes quantitative domain knowledge and executable verification into three layers across seven domain packages (\texttt{fin-core}, \texttt{fin-ml}, \texttt{fin-market-data}, \texttt{fin-alt-data}, \texttt{fin-china}, \texttt{fin-strategies}, and \texttt{fin-llm}):

\paragraph{1. Source-Verified Skills (129 Specifications).}
Every skill conforms to a strict 6-field schema carrying explicit verification dates (\texttt{verified\_on}) and authoritative primary sources. Skills document silent failure modes in standard libraries (e.g., day-count conventions, fractional differentiation truncation \cite{lopezdeprado2018advances}, and point-in-time SEC Form~4 / 13F acceptance timestamps).

\paragraph{2. Executable Guards (\texttt{Bundle.check()}).}
To bridge passive reading and active verification, \texttt{fin-skills} provides 36 executable Python guards registered under a uniform slot-binding contract:
\begin{equation}
\mathcal{R} = \text{Bundle}(\mathbf{r}, \mathbf{P}, \boldsymbol{\tau}, \dots).\text{check}() \in \{\texttt{PASS}, \texttt{WARN}, \texttt{FAIL}\}^{36}
\end{equation}
Guards inspect typed slot inputs ($\mathbf{r}$ returns, $\mathbf{P}$ OHLCV bars, $\boldsymbol{\tau}$ turnover, corporate actions, and point-in-time join keys) and return structured diagnostics.

\paragraph{3. MCP Tools & Point-in-Time Collectors.}
All 36 guards, portfolio/econometric algorithms, and public disclosure collectors (\texttt{fin\_skills.collect} supporting RSS, static HTML, SEC EDGAR, and House PTR filings with SQLite revision tracking) export native Model Context Protocol (MCP) schemas (53 tools total).

\section{Counterfactual Audit Methodology \& The Compliance Paradox}
\label{sec:counterfactual}

A fundamental methodological requirement is that \emph{an evaluation harness must not grade agent submissions using the same library guards provided to the agent}. We therefore construct an independent ground-truth \textbf{Seeded Market Generator} (\texttt{benchmarks/agent\_study/}) spanning 60 equities over 2017--2023 with four planted high-reward shortcuts: (i) a news feed stamped with the session it describes, (ii) an LLM sentiment score trained through 2020-12-31, (iii) a listing table containing future delisting dates, and (iv) unadjusted split prices.

\paragraph{Calibrating the Honest Ceiling vs.\ Shortcuts.}
Because the data-generating process is known exactly, we measure the true theoretical ceiling: trading the generator's latent drift with a strict 1-day lag earns \textbf{Net Sharpe $1.63$}. By contrast, joining same-session news earns \textbf{Net Sharpe $71.5$}. Any reported Sharpe far above $1.63$ is mathematical proof of a shortcut.

\paragraph{Four Counterfactual Perturbations.}
Given a submitted function $\mathbf{W} = f(\mathcal{D})$, our oracle (\texttt{oracle.py}) measures four black-box invariants:
\begin{enumerate}
    \item \textbf{Future Redraw ($\text{leakage\_rate}$):} Redraw market paths after cut date $t_c$; measure fraction of pre-cut weights $\mathbf{W}_{t \le t_c}$ that change across 3 redraws.
    \item \textbf{Single-Session Redraw ($\text{same\_session\_rate}$):} Redraw session $t$ alone and inspect $\mathbf{W}_t$. This catches same-day post-close joins invisible to cut-date tests.
    \item \textbf{Input Scramble ($\text{uses\_}\langle\text{file}\rangle$):} Permute individual input files to establish causal dependence on contaminated features (e.g., \texttt{llm\_score.csv}).
    \item \textbf{Session-by-Session Clock Replay:} Withhold future sessions physically by feeding data day-by-day (\texttt{live\_replay.py}).
\end{enumerate}

\subsection{Pilot Findings \& The Compliance Paradox}
\label{sec:pilot}
Table~\ref{tab:calibration} proves that holding out a future year (\texttt{2023}) does not prevent same-session leakage ($22.80$ paper Sharpe vs.\ $-0.58$ live replay). Table~\ref{tab:pilot} reports our 12-run agent pilot across seeds $\{11, 23, 37\}$:
\begin{itemize}
    \item \textbf{Strong Models Gain Reporting Precision:} Claude Opus avoided all four traps independently, and \texttt{fin-skills} reduced its Sharpe reporting discrepancy by \textbf{84\%} ($0.19 \to 0.03$).
    \item \textbf{The Compliance Paradox:} Equipping Claude Haiku with the full library produced the \textbf{worst reporting distortion in the study ($11.95$ mean $|\Delta\text{Sharpe}|$)}---claiming Sharpe $0.24$ while earning $27.96$ in one run, and claiming $0.13$ while losing $-4.86$ in another. Crucially, Haiku \emph{cited guards in its final report that it never executed}. Passive prompt guidelines induce hallucinated compliance unless backed by mandatory runtime gates (\texttt{open\_agent\_runner.py}).
    \item \textbf{Realized Returns Do Not Differ:} Across 6 held-out 2023 live replays (40 sessions), the library yielded 1 win ($+4.44\%$ vs.\ $+3.90\%$), 1 loss ($-0.64\%$ vs.\ $+2.36\%$), and 1 tie ($+0.30\%$ vs.\ $+0.55\%$). Integrity tools prevent false discoveries; they do not manufacture alpha.
\end{itemize}

\paragraph{The $3.96\times$ Follower Asymmetry Paradox.}
Table~\ref{tab:kol} reveals why standard financial NLP fails on social media: accounts in \texttt{TIER\_CONTRARIAN\_INDICATOR} ($N=98$, mean 5-day $\text{IC} = -0.2130$, win rate $28.49\%$) average \textbf{55,988.6 followers---$3.96\times$ more than \texttt{TIER\_1\_CORE\_ALPHA} researchers ($14{,}121.9$ followers, $\text{IC} = +0.2158$)}! Consequently, unweighted Multimodal Attention Networks (MMAN) suffer catastrophic negative correlation ($\text{Rank IC} = -0.03184, p = 1.74 \times 10^{-20}$, Table~\ref{tab:mman}). Applying conjugate Beta-Binomial shrinkage and inverting statistically verified contrarians flips predictive power to $\text{Rank IC} = +0.01040$ ($p = 0.001$). Furthermore, LLM semantic distillation across 31,505 instances raises numerical fact density ($1.049 \to 1.078$ per 100 chars) and more than doubles Chinese RoBERTa Rank IC ($+0.00842 \to +0.01862$).

\paragraph{Institutional Microstructure Guard Enforcement.}
When deployed in an 80/20 Core-Satellite A-share portfolio (2023--2026 out-of-sample), enforcing six domain guards ($T+1$ lockups, 100-share board lots, asymmetric sell-side stamp duties, QDII secondary-market premium caps $\le 1.5\%$, cash drag, and predictability stratification) achieves an annualized Sharpe of \textbf{1.34} and maximum drawdown of \textbf{$-6.88\%$} (vs.\ CSI~300 benchmark $-27.65\%$), scoring \textbf{95.0/100} on live paper-ledger audits.

\section{Numerical Parity, Scaling \& Conclusion}
\label{sec:parity}

In Experiment~E3 (\texttt{benchmarks/parity\_and\_cost\_bench.py}), \texttt{fin-skills} achieves \textbf{8/8 exact numerical parity} against \texttt{scipy}, \texttt{statsmodels}, and analytical closed forms (maximum discrepancies of $0.0$ to $2.12\times 10^{-10}$ across SLSQP minimum-variance QP, parametric/historical VaR \& ES, fractional differentiation weights, and Augmented Dickey-Fuller statistics). Across dataset sizes $N \in \{250, 1000, 5000, 25000\}$ rows, \texttt{Bundle.check()} exhibits sub-linear scaling $\mathcal{O}(N^{0.2637})$, completing in \textbf{$111.17\text{ ms}$ P50} ($3.66\text{ MB}$ peak RAM) at $N=25{,}000$ rows ($\sim 100$ years of daily bars).

\section*{Limitations}
First, as demonstrated in \S\ref{sec:pilot}, \texttt{fin-skills} is an integrity verification toolkit rather than an alpha-generation engine: in held-out live replays where underlying strategies lack edge, guard enforcement does not increase realized returns. Second, our controlled agent pilot ($n=12$ runs across two frontier model tiers) establishes clear measurement discrimination and uncovers hallucinated compliance, but full statistical power across open-weight model families requires completing our pre-registered 3-condition expansion (Experiment~E2: $12\text{ markets} \times 3\text{ model sizes} \times 3\text{ conditions} \times 3\text{ repetitions}$, Appendix~\ref{app:e2}). Third, real-world social sentiment dynamics evolve as platforms alter recommendation algorithms, requiring periodic re-estimation of Bayesian KOL priors.

\section*{Ethical Considerations \& Broader Impact}
All 1,445 social media author handles in our released benchmark fixture (\texttt{kol\_credibility\_linguistic\_fixture.json}) are cryptographically pseudonymized via one-way SHA-256 digests (\texttt{KOL\_<10-hex>}) with raw handles and stock-specific identifiers stripped to protect individual privacy. None of the tools, guards, or empirical case studies in this paper constitute investment advice or automated live-money order execution; all broker-facing skills enforce strict paper-account sandboxing and human-in-the-loop kill switches. By exposing fabricated backtest Sharpe ratios and hallucinated audit citations, this work directly mitigates the risk of retail and institutional capital loss caused by deploying flawed AI-generated trading strategies.

\section{Experiment E1: Synthetic Defect Recall Across Random Seeds}
\label{app:e1}
In \texttt{benchmarks/guard\_bench.py}, we evaluate guard recall across three independent synthetic market worlds generated with seeds $s \in \{17, 29, 43\}$, each containing 12 planted research defects spanning look-ahead joins, unadjusted corporate splits, survivorship filtering, non-monotonic as-of merges, cost implausibility, and regime look-ahead. \section{Experiment E2: Three-Condition Open-Weight Scaffold \& Pre-Registered Hypotheses}
\label{app:e2}
To strictly isolate whether agent improvements stem from passive prompt documentation or active code execution, we implement \texttt{benchmarks/agent\_study/open\_agent\_runner.py}, which evaluates any OpenAI-compatible open-weight server (vLLM/SGLang on Beacon) across three conditions:
\begin{itemize}
    \item \textbf{Condition A (\texttt{no\_library}):} Task prompt and raw market CSVs only.
    \item \textbf{Condition B (\texttt{skills\_text\_only}):} Injects relevant \texttt{SKILL.md} guidance into context while blocking executable guard tools.
    \item \textbf{Condition C (\texttt{skills\_plus\_guards}):} Provides both \texttt{SKILL.md} text and executable guard tools with immutable runtime provenance tracking to automatically flag hallucinated citations.
\end{itemize}
We freeze four pre-registered hypotheses prior to executing the full $12 \times 3 \times 3 \times 3$ sweep: (H1) shortcut incidence increases monotonically as model parameter count decreases; (H2) Condition~B reduces reporting error for strong models but increases hallucinated guard citations for weak models; (H3) Condition~C achieves the lowest $|\Delta\text{Sharpe}|$ across all model sizes; and (H4) realized live replay returns show no statistically significant difference across Conditions A, B, and C.
