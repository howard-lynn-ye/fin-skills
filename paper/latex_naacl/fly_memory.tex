\section{Fruit-fly-inspired learning with checked feedback}
\label{sec:fly}
This application extends the library from assisting fixed models to checking the
experience used by an online learner. Its research question is whether memory operating
over different timescales, updated from checked delayed outcomes, can support decisions
to enter, persist, exit, and revisit opportunities under changing conditions and
transaction costs. These policy capabilities remain development objectives.

\paragraph{Memory component.}
Our biological starting point is the mushroom-body memory model of
\citet{huang2024memory}, which studies interactions between short- and long-term memory
units. The repository separates a numerical reproduction harness from an online
adaptation. The adaptation advances its retention clock using observed conditioning
events and reads memory without changing its state. Mapping signed financial returns
to reinforcement and interpreting neuronal readouts as preferences are engineering
choices. They are not validated biological correspondences, and the readout is not a
calibrated expected return. The reproduction and derived model code are distributed
as a separately installed GPL-3.0-or-later extension. The core library provides its
adapter and model-card interface without bundling the extension or circuit parameters.

\paragraph{Connection to the library.}
The implemented feedback interface treats an entry and its subsequent holding periods
as one completed decision episode. Given positive, cost-inclusive account values
$W_0,\ldots,W_T$, its learning target is
\begin{equation}
G = \sum_{t=0}^{T-1}\log(W_{t+1}/W_t)
  = \log(W_T/W_0).
\end{equation}
This undiscounted complete-episode target includes entry costs and later holding
outcomes. It requires the episode to end before the result can be used. The interface
checks interval continuity, return accounting, and availability timestamps, and invokes
the library's source-lineage guard. Pending feedback waits; invalid feedback is
rejected; valid negative returns remain learning signals. A completed receipt can be
consumed once. The source account values still require independent execution
reconciliation: these checks cannot establish that supplied values are authentic.

\paragraph{Current evidence and remaining comparison.}
Earlier custom sparse controllers made market decisions, but their development results
did not establish a consistent financial advantage. Architecture diagnostics identified
a mismatch between one-interval rewards and persistent holdings, return clipping that
can change preference ordering, and impaired adaptation under repeated reward reversals.
Those findings concern the tested implementations, not the suitability of mushroom-body
models in general. The newer memory interface uses supplied outcomes in controlled
learning cases; it does not yet autonomously choose entry, holding duration, or exit.
It is separate from the LLM tool-use experiment in the preceding section.

The compact-memory benchmark now includes a frozen-memory control with the same
volatility gate as the learned-memory arm, using identical data, costs, chronological
splits and seeds. This separates the contribution of learning from that of the risk
gate. No result for the newly added control has been recorded. The volatility gate
controls exposure; it is distinct from the delayed-feedback checks described above.

The proposed comparison will hold information, actions, costs, and learning targets
constant across controllers with and without feedback checks. Linear and dense
controllers, non-biological models with matched memory timescales, and ablations of
memory interactions are needed to distinguish the contributions of feedback validation
and memory structure. Evaluation must measure adaptation, exit behavior, turnover, and
net performance on untouched periods. This model-development contribution is therefore
an implemented research direction with explicit tests still required, not evidence
that biological inspiration or library access yields higher returns.
