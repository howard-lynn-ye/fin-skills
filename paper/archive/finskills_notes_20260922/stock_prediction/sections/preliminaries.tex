\section{The \texttt{fin-skills} Verification \& Memory Architecture}
\label{sec:preliminaries}

\texttt{fin-skills} connects dated domain guidance, executable algorithm adapters, timestamp-aware collection, and structured research checks across seven packages (\texttt{fin-core}, \texttt{fin-ml}, \texttt{fin-market-\allowbreak data}, \texttt{fin-alt-\allowbreak data}, \texttt{fin-china}, \texttt{fin-\allowbreak strategies}, and \texttt{fin-llm}). The frozen repository snapshot comprises \textbf{129 skill specifications}, \textbf{48 algorithm--backend catalog entries}, \textbf{36 registered research guards}, and \textbf{56 JSON/MCP callable tools}.

\paragraph{Progressive Skill Routing \& Algorithm Catalog.}
Each skill obeys a machine-validated 6-field schema carrying explicit verification dates (\texttt{verified\_on}) and primary citations. Rather than stuffing all 129 documents ($369{,}315$ tokens) into context, agents query a lightweight catalog (\texttt{list\_algorithms}, \texttt{search\_skills}) and load targeted specifications (\texttt{read\_skill}) or execute compatible algorithms (\texttt{run\_algorithm}), reducing prompt tokens by $\mathbf{98.91\%}$ ($4{,}039$ tokens/task) with $100\%$ guard recall (\S\ref{sec:autonomous_pillar}).

\paragraph{Executable Guards (\texttt{Bundle.check()}) \& Checked Episode Feedback.}
To bridge passive documentation and runtime enforcement, 36 executable Python guards evaluate candidate artifacts and online learning episodes over a unified slot-binding contract:
\begin{equation}
\resizebox{0.88\columnwidth}{!}{$\displaystyle \mathcal{R} = \text{Bundle}(\mathbf{r}, \mathbf{P}, \boldsymbol{\tau}, \mathcal{C}).\text{check}() \in \{\texttt{PASS}, \texttt{WARN}, \texttt{FAIL}\}^{36},\quad G = \sum_{t=0}^{T-1}\log\!\left(\frac{W_{t+1}}{W_t}\right) = \log\!\left(\frac{W_T}{W_0}\right)$}
\end{equation}
where $\mathbf{r}$ denotes strategy returns, $\mathbf{P}$ OHLCV prices, $\boldsymbol{\tau}$ turnover, $\mathcal{C}$ point-in-time corporate action and filing timestamps, and $G$ the cost-inclusive complete-episode log-wealth target passed to online mushroom-body memory units \citep{huang2024memory} only after interval continuity, \texttt{avail} timestamp, and source-lineage guards pass (\S\ref{sec:fly_pillar}). In Experiment~E3 (\path{benchmarks/parity_and_cost_bench.py}), our direct primitives achieve \textbf{\ParityPassed{}/\ParityTotal{} numerical parity} against \texttt{scipy}, \texttt{statsmodels}, and analytical solvers (maximum error $1.14\times 10^{-8}$ on SLSQP minimum-variance QP, $0.0$ on HRP and Ledoit-Wolf shrinkage), while \texttt{Bundle.check()} scales sub-linearly as $\mathcal{O}(N^{0.3894})$ up to $N=100\text{k}$ rows ($218.97\text{ ms}$ P50, $14.73\text{ MB}$ RAM).
