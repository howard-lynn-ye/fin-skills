# 金融 Agent 的专业工具使用与经验学习

更新：2026-09-22。依据本轮用户确认，本文以研究与决策能力为主线，检查与审计作为
执行和学习反馈的支撑机制。本文件是当前写作定位；早期审计中心的大纲保留为历史记录。

工作标题：**From Tool Access to Research Capability: Tools and Memory for Financial Agents**

## 中心问题

金融 Agent 如何把可调用的专业方法，转化为能够选择、执行并从经验中改进的研究能力？

研究能力体现为：根据任务和数据选择适用方法，理解并使用工具输出，完成有用的分析或
决策，以及根据后续经验调整选择。减少错误是可能的收益和有效性指标之一，不能代替
任务质量、适应能力和资源成本。当前稿讨论这条能力形成路径，尚未证明完整系统实现了
持续改进。

## 各部分的必要角色

| 部分 | 改变什么 | 要回答的问题 | 当前证据 |
| --- | --- | --- | --- |
| FinSkills | 可发现的知识、专业方法与执行接口 | Agent 如何选方法、设参数、使用输出？ | 已完成自主使用开发实验 |
| HiSTrim | 单次任务内保留的历史表示和 KV | 在有限资源下，哪些历史信息仍能支持决策？ | 原稿推荐任务结果；金融接入待验证 |
| 持久记忆 | 跨 episode 保存和更新的状态 | 哪些经验改变了后续选择，是否改善适应？ | 数值适配器和延迟反馈接口；完整选择策略待接入 |
| 检查与审计 | 执行记录和反馈使用条件 | 哪些结果实际产生、哪些反馈可被学习？ | 回归检查和审计可行性实验 |

HiSTrim 的任务内上下文与跨 episode 持久记忆是不同对象。果蝇模型内部也包含不同时间
尺度的记忆动力学，不能把它的短期单元直接等同于 HiSTrim。检查通过不等于来源真实，
有效亏损仍是学习信号，盈利也不自动证明方法选择正确。

## 论文的三个研究问题

1. **专业方法的选择和使用：** 领域知识、固定工具输出与自主选择分别怎样影响决策？
   评价实际选择、适用条件和最终任务质量，同时记录预算和风险暴露。
2. **任务内的信息保留：** 固定模型和工具后，选择性上下文怎样影响证据保留、任务质量、
   KV 占用和实际延迟？压缩率、置信度不能独自作为能力提升的证据。
3. **跨 episode 的经验作用：** 更新记忆是否改变下一次选择，能否迁移到新的任务或时期？
   冻结记忆、同样风险门控的控制组及非生物记忆基线用于区分学习的贡献。

## 当前最直接的观察

自主使用实验记录了 64 次有效决策与 43 次成功工具调用，但两个模型的自主工具条件都
没有在平均代理收益上超过各自无库控制。数值来自原有实验，未因这次改写而改变。

这说明当前环境下“完成调用”与“改善结果”需要分别衡量。它没有证明工具一般无效，
也没有确定原因是上下文、记忆或工具选择。方法适用性、输出理解、风险暴露、计算预算和
市场路径都是需要区分的解释。新的主线把这一观察作为研究动机，而不是把它改写成已被
HiSTrim 或持久记忆解决的问题。

## 对照实验的写作边界

- 方法选择没有天然唯一正确答案；适用条件与任务评分准则需独立确定。
- 上下文比较固定模型、信息截止时间和工具，比较全上下文、简单预算匹配保留和 HiSTrim。
- 记忆比较固定动作、反馈、风险门控和预算，比较无记忆、冻结记忆、更新的非生物基线与
  当前记忆组件；再检验上下文与记忆的交互。
- 反馈有效性作为单独消融；不把拒绝所有反馈或拒绝所有任务视为改进。
- 学习效果通过未来未用于开发的任务或时期测量；实际调用、token、延迟、交易成本和
  风险暴露一并报告。不同推理种子不等于独立市场。
- 上述设计是下一步实验要求，不能写成已运行或预注册完成的结果。
